# Wedding-invitation-inspired visual refresh

## Goal
Give The Merit Circle a warmer, unmistakably matrimonial identity inspired by floral Hindu wedding invitations—without losing its private, mature, candidate-led character.

## What will change
- Add restrained botanical ornamentation: fine floral/vine corner details, delicate separators, and a few invitation-style framed moments on the public landing and membership application pages.
- Enrich the existing linen, forest, and brass palette with a muted marigold/rose accent, keeping ornament secondary to content and calls to action.
- Carry the refreshed identity into shared public branding where it fits, while keeping member search, forms, and other functional screens calm and legible.
- Preserve mobile usability, contrast, reduced-motion behavior, privacy messaging, and the existing brand/tagline.

## Visual direction
Use traditional Indian invitation florals as a quiet design reference—fine botanical linework and elegant border/corner details, not dense patterns, clip-art, or a ceremonial-card imitation. Keep the overall presentation refined and contemporary.

## Technical approach
Use semantic theme tokens and a reusable decorative treatment; use a lightweight floral visual asset only where it improves the public-page composition. Keep the existing component library and app behavior unchanged.

## Verification
Review the landing and application at mobile and desktop sizes, then run the project’s applicable type, lint, test, and build checks.
