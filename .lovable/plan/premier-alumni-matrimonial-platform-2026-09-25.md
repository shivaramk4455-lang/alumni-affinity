# Premier Alumni Matrimonial Platform

## Goal

Build a polished, mobile-first matrimonial experience where verified candidates lead and invited families support them, with a discreet heritage aesthetic and clear institutional trust signals.

## What I’ll build

- A responsive home page with quiet editorial positioning, eligibility standards, privacy guarantees, membership process, and a formal compliance footer.
- A multi-step application and verification experience covering identity, education proof, life trajectory, values, relocation, photos, privacy controls, and parent co-pilot invitation.
- A verification dashboard preview with a clear switch between candidate and parent co-pilot perspectives, status tracking, privacy state, and next actions.
- Shared navigation and visual language across every page, including strong mobile layouts and accessible interaction states.

## Visual direction

- Warm linen surfaces, midnight ink and heritage forest structure, muted brass details, and crisp hairline borders.
- High-contrast editorial serif headings paired with a clean geometric sans-serif for controls and body text.
- Restrained motion, formal iconography, no gradients, glass effects, blobs, cartoons, or decorative gimmicks.

## Technical details

- Use separate routes for Home, Apply, and Dashboard so each flow is directly shareable and has unique metadata.
- Keep the experience front-end only: entered wizard information and uploads remain temporary preview state and are not sent or stored.
- Add client-side validation, accessible form labels, responsive progress controls, and working candidate/co-pilot dashboard switching.
- Define all color and typography values as reusable design tokens and use the existing interface controls where available.
- Verify the finished experience at desktop and mobile sizes, including interactive wizard navigation and dashboard switching.
